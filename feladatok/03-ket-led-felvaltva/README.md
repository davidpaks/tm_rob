# 03 – Két LED villogtatása felváltva

## Cél
Két LED vezérlése úgy, hogy mindig pontosan az egyik világítson.

## Alkatrészek
- Arduino Uno
- 2 db LED (piros, kék)
- 2 db 220 Ω-os ellenállás

## Bekötés
- 8-as láb → 220 Ω → piros LED anódja; katód → GND
- 9-es láb → 220 Ω → kék LED anódja; katód → GND

## Elvárt működés
A két LED 1 másodpercenként helyet cserél: amikor az egyik világít, a másik nem.
