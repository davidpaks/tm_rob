# 06 – Számlálás 0-tól 9-ig

## Cél
A 7 szegmenses kijelzőn a számok folyamatos, körbe-körbe számlálása.

## Elvárt működés
A kijelző 0-tól indulva másodpercenként eggyel nagyobb számot mutat. A 9 után újra a 0 következik.

## Magyarázat
- A bekötés és a `display()` függvény megegyezik az előző feladatéval.
- A `szam` változó a `loop()` minden lefutásakor eggyel nő; ha eléri a 10-et, visszaáll 0-ra.
